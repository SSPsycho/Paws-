# PAWS — тестовый сайт

## Что внутри
- `index.html` — содержание и структура страницы
- `styles.css` — оформление, адаптивность и анимации
- `script.js` — фильтр каталога и мобильное меню

## Быстрый просмотр
Откройте `index.html` в браузере. Для корректной работы всех возможностей интернет не обязателен, но шрифты загружаются из Google Fonts.

## Что заменить перед публикацией
1. В `index.html` найдите `https://t.me/your_username` и замените на ссылку своего Telegram.
2. Демонстрационные карточки и иллюстрации пока сделаны CSS-фигурами. Позже можно заменить их фотографиями ваших изделий.
3. Измените название `PAWS` на название бренда.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/(root)`, затем Save.
6. После завершения публикации GitHub покажет адрес сайта.

## Публикация на Cloudflare Pages
1. Создайте аккаунт Cloudflare.
2. Откройте Workers & Pages → Create → Pages.
3. Выберите Direct Upload (если доступен в интерфейсе) и загрузите папку проекта или ZIP.
4. Нажмите Deploy. Cloudflare выдаст адрес `*.pages.dev`.

Это статический демонстрационный сайт-витрина. Корзины, базы заказов и онлайн-оплаты в нём пока нет.
